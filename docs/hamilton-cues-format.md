# The Hamilton cue sequence — data format

Two files drive the auto-timed show in `midtown.html`. Both are generated or
written by tools and agents; neither is hand-edited casually.

## 1. `assets/hamilton-eos.json` — the show file's vocabulary and real cues

Generated by `tools/hamilton-cues.py` from the Eos Nomad export
(`Downloads\The Hamilton Programming Project - Intro - Rev A.csv`, not
committed; ETC non-commercial, like `assets/hamilton-rig.json`).

```jsonc
{
  "source": "...", "generated_by": "tools/hamilton-cues.py",
  "frame": "focus points are SET-LOCAL metres (the set GLB's frame, the same transform as hamilton-rig.json: (x, z+0.2651, 3.96-y) from Eos X/Y/Z)",
  "channels": { "93": { "type": "mac-viper", "eosType": "Mac_Viper_Performance_hamilton__main", "label": "...", "gel": null } },
  "groups":   { "12": { "label": "FOH Wash", "ch": [101, 102] } },
  "presets":  { "49": { "label": "...", "ch": { "3": PARAMS } } },
  "colorPalettes": { "5": { "label": "...", "ch": { ... } } },
  "beamPalettes":  { "...": { "label": "...", "ch": { ... } } },
  "focusPalettes": { ... }, "intensityPalettes": { ... },
  "effects": { "3": { "label": "...", "type": "...", "notes": "..." } },
  "gobos": { "mac-viper": { "2": "Construction" } },   // (type, Gobo_Select) → our gobo name, learnt from labelled beam palettes
  "cues": [ CUE, ... ]                                 // the REAL cues, list 1, in cue order, as Eos stored them (tracked deltas)
}
```

### PARAMS — one channel's parameters (Eos-native units, every key optional)

| key | meaning |
|---|---|
| `i` | intensity 0–100 |
| `focus` | `[x, y, z]` set-local metres the beam aims at (movers) |
| `pan`, `tilt` | Eos degrees (kept for reference; `focus` wins) |
| `cmy` | `[c, m, y]` 0–100 (Viper, VL3500) |
| `cto` | 0–100 |
| `rgb` | `[r, g, b]` 0–100; `w`, `a` (amber), `lime`, `indigo` 0–100 (LEDs) |
| `cw` | colour-wheel slot name, if known |
| `gobo` | our gobo name (`LX_GOBOS` in midtown.html), or `"slot:N"` if unknown |
| `goboRot` | gobo rotation, degrees per second (+ clockwise), 0 = still |
| `zoom` | beam angle, degrees |
| `edge`, `iris` | 0–100, informational |
| `ref` | where the values came from, e.g. `"preset 49"`, `"cp 5"` |

Also emitted by the converter: `mark` (the cue a move-in-dark value is
pre-set for), `blk` (blocked), `fx` (the effect running on the channel),
`cyan` (the Lustr's LED cyan), `frost` (diffusion), `goboIdx` (gobo index
angle, degrees) and `goboSpd` (the raw rotate value), and per-channel `time` /
`delay`. Cues and parts may also carry `marked`, `assert`, `delays`, `fx`,
`macros`, `curve`, `rate`, `notes`, `utility`. Blocked and mark rows sit in a
parted cue's own `ch`. Groups carry their channel list in `ch` (and Eos
sub-groups in `sets`); the real cues address channels, never groups, but a
reconstruction may use `"g:N"`.

A reference may stand for the values: `{ "preset": 49 }`, `{ "cp": 5 }`
(colour palette), `{ "bp": 12 }` (beam palette), `{ "fp": 3 }`, `{ "ip": 2 }`
— the player resolves it from this file, per channel, and explicit keys beside
it win.

### CUE

```jsonc
{
  "q": "192",                       // cue number as a string ("36.1", "204.02")
  "label": "+++1/7 \"BeBack\"",
  "time": { "up": 5, "down": 5, "focus": 6, "color": 5, "beam": 5 },  // seconds; missing = up
  "delay": 0,
  "follow": null,                   // seconds: auto-GO the next cue this long after this one's GO (Eos "F2.1")
  "link": null, "block": false, "mark": false,
  "scene": "You'll Be Back",        // Eos scene text, when the cue starts one
  "parts": [ { "part": 2, "label": "wash stagger up", "time": {...}, "delay": 0.5, "ch": { "3": PARAMS } } ],
  "ch": { "3": PARAMS, "g:12": PARAMS }   // part-less changes; "g:N" = every channel of group N
}
```

Cues TRACK: a cue holds only what changed; everything else holds from the cue
before. A blackout (`+++FTB+++`) is a cue that takes every channel to 0.

## 2. `assets/hamilton-show.json` — the timed sequence for the whole show

```jsonc
{
  "album": "Hamilton (Original Broadway Cast Recording), 2015",
  "tracks": [ { "id": "1-01", "act": 1, "n": 1, "title": "Alexander Hamilton", "len": 236 },
             { "id": "2-01", ..., "hold": "Intermission" } ],   // hold: the player stops at the END of the track before this one (its last cues fired), house lights up, and waits for Play
  "cues": [
    { "q": "192", "track": "1-07", "at": 0.0, "real": true },          // a real cue: content from hamilton-eos.json by q
    { "q": "205", "track": "1-07", "at": 41.5, "real": false,           // a reconstruction: content here, same CUE shape
      "label": "Verse 2 — George to the stairs", "time": { "up": 3 }, "ch": { "g:40": { "i": 80, "cp": 7 } },
      "why": "one line: what moment this is and what it is modelled on" }
  ]
}
```

- `at` is seconds into that album track. Every cue has its own `at`; a real
  cue's Eos follow is resolved into the next cue's `at`.
- Reconstructed cue numbers sit in the gaps of the real numbering, in order
  (the real stack runs 0.5 → 1271; the album's two acts are one cue list).
- Labels describe the moment. **No lyrics** beyond a song's title or a word
  the Eos labels already use; never a line of the text.
