# The Maker Pen — plan, PRs 1–17

**Binding spec:** `docs/superpowers/specs/2026-08-17-maker-pen-design.md`
(RULINGS **FE–FW**). Read it first. Nothing here overrides a ruling there.

**One concern per PR. Never stacked.** Each PR is based on fresh `main`,
rebuilt, retested, two-stage reviewed, merged, then post-merge verified
(`main` rebuilds byte-identical, `docs/ARTNET.md` reproduces, full suite on
the merged result, branch deleted local and remote).

**Every `src/` change regenerates `docs/ARTNET.md` from `sh`, never
PowerShell.** Every new assertion is negative-checked by **sha**, with the
mutation proved present in the BUILT file and proved to have moved its sha,
and every restore proved byte-identical.

## Phase 1 — the pen core (`p4d` model, then `p9b` surface)

### PR 3 — the spec and this plan
Docs only. No `src/` change, so no rebuild and no map regeneration.

### PR 4 — `p4d`: the MAKER registry and the seven primitives
`MAKER[venue] = {shapes:[], groups:[], boards:[], ink:{tris:0, n:0}}` holding
ids. `makerMint(kind, pose)` regs a `pen` body; seven cached unit geometries
(RULING FK). Named in `makeBodyMesh` AND `BODY_LABEL` (RULING FS) — **not** in
`BUILD_KINDS` yet, that is PR 6.
*Negative check:* rename the `pen` arm in `makeBodyMesh` → a minted shape
comes back a 0.485m profile spot and the geometry assertion fires.

### PR 5 — `p4d`: freeze, and the wake contract
`makerFreeze` / `makerUnfreeze` (RULINGS FG, FH). Frozen sets `b.rest`,
skipped by `updateBodies`; unfrozen falls. **`makerUnfreeze` calls
`wakeBodies(venue)` unconditionally, first thing.**
*Negative check:* drop the `wakeBodies` call → a body resting on the shape
hangs in mid-air for a rota and the assertion fires. This one is the reason
the PR exists; write it first.

### PR 6 — the six wood filters widen to *unfrozen build kind*
RULING FI. p4c:483, 614, 791, 826, 845, 861. A frozen shape refuses a nail; an
unfrozen one takes one; a lantern still refuses.
*Negative check:* widen one filter to "any body" → the lantern clause fires.
**Six mutations, one per site** — a single filter left un-widened is a silent
half-fix, and this repo has had exactly that.

### PR 7 — `p4d`: ink, and the two caps the pen must book itself
RULINGS FJ, FR. Triangle total + shape count. **The pen calls
`venueBuildCount()` / `venueLooseCount()` before every mint** — `orderPlace`
is the only enforcement point today and the pen bypasses it entirely.
*Negative check:* remove the cap call → mint past 150 and the assertion fires.

### PR 8 — `p4d`: undo and redo
RULING FM. Bounded stack, pen actions only.
*Negative check:* make redo replay the wrong direction → the round-trip
assertion fires.

### PR 9 — `p4d`: serialisation through the MAKER layer
RULING FP. The pen's own list — kind, pose, colour, frozen — replayed through
`regBody`/`makeBodyMesh`. **`buildSerialize`'s `BUILD_KINDS` gate at p4c:1206
is NOT widened.** Must tolerate absent or malformed fields without throwing:
`buildLoad`'s catch deletes the save and leaves a half-built world — a cliff,
not a net.
*Negative checks:* (a) drop a field from the writer → the round-trip fires;
(b) feed a malformed record → it must not throw.

### PR 10 — `p9b`: the fifth belt tool
RULING FO. `vrToolPen` builder; `mk('pen', …, 0.24, -0.18)` appended LAST;
`vrDraw` toast arm; `vrToolFire` arm; `vrHolster` teardown; `vrOnEnd`. The
belt comment is corrected — the separation that disambiguates a draw is
**0.44**, not 0.22, and the existing belt does not meet it.
*Negative check:* move the new holster inside 0.22 of the nail gun → the
separation assertion fires.

### PR 11 — `p9b`: the create ray and the gizmos
RULING FL, FN. The pen's OWN raycaster — `vrCastWorld` cannot be reused.
Rotation reuses the 45° grid, hoisted to one named constant from six literals;
p9:2590 does NOT follow it. A new `VR.held.kind` gets a branch **before**
p9:3118 or it crashes on `VR.held.rope.ls`. The pen's label joins the
`vrLabel` singleton chain.
*Negative checks:* (a) remove the held-kind branch → the fall-through crash
fires; (b) point the ray at a wall → the building refuses.

### PR 12 — `p9b`: the palette page
A `vrPagePen(g, P)` on the main console, tenth tab. **Depends on PR 2.**
