# assets/

Delivered set models go here: `bj-<set>.glb` (and `bj-dress-<dressing>.glb`), modelled to `docs/MODELING.md`.
A missing file is a NORMAL state — the game falls back silently and the built stand-in keeps playing.
Each delivered model lands via its own PR: scaled, placed, walkables wired, budgets verified, suites green.

## Third-party models

`midtown-auditorium.glb` — NOT yet wired into the game. Built from `source/midtown/scene.gltf` by
`tools/blender/midtown_theatre.py` (screen removed, brown proscenium recoloured to the walls' grey,
speakers decimated). Credit, required by its licence:

`hamilton-set.glb` — WIRED IN (RULING FE, 2026-10-11): `p5i` fetches it when HAMILTON loads and
it replaces the hand-built stand-in. Built by `tools/blender/hamilton_set.py` from the set model
inside ETC's *Hamilton Programming Project* (the `Hamilton Full Set` COLLADA inside the show
file's `working.a3d`): Rod Lemmond's model of David Korins' scenic design, with the theatre's own
proscenium, borders and floor stripped out, five generated materials, 68k triangles. ETC releases
the project for **non-commercial use only** (see its Project Guide) — keep that in mind if this
repository ever goes public. The source file is not committed; the script names where it lives.

`hamilton-rig.json` — NOT yet wired into the game. Generated by `tools/hamilton-rig.py` from the
patch of the same ETC *Hamilton Programming Project* (`Scene/Patch.json` and `Scene/Fixture.json`
inside the show file's `working.a3d`): every lighting unit ETC patched, with its place and aim in
the frame of `hamilton-set.glb`, plus six placed by hand. Derived from the same pack, so the same
**non-commercial** licence applies. The pack is not committed; `docs/HAMILTON-RIG.md` says how to
regenerate the file.
