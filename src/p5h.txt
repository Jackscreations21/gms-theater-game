
/* ============================================================================
   BEETLEJUICE — the fifth production, and the first taken off a recording

   Two different kinds of work wear one name here, and the line between them
   matters more than anything else in this file:

     MEASURED     cue times, fade durations, blackouts, the act break.  They
                  came off a recording of a real performance with
                  tools/video.js and they are quoted in the cue comments as
                  the times they actually are.
     INTERPRETED  every channel level, every focus, and all of this scenery.
                  We are rendering lit AREAS onto our own 25-channel rig,
                  which is not the rig they used.

   RULING AV (2026-08-10) REPEALS RULING AO for this show.  The owner:
   "remove the cluase entirely that it has to be our onw shapes. make the
   sets look as close to the real stuff as you can get it".  So this one is
   MODELLED ON THE PRODUCTION — proportions, colours, lettering and all —
   where the other four remain interpretations in their own vocabulary.  AO
   is left standing in its own spec, marked superseded: a ruling that got
   reversed is worth more on the record than one quietly deleted.

   The set changes are SCENES (p5c): one stage, and the sets take turns on
   it.  That machinery was built for this show, removed with it, and this is
   the first production to use it.  A scene that is off has its layers
   disabled, so it costs no draw call and no raycast while it waits.
   ========================================================================== */

/* ---------------------------------------------------------------------------
   THE CHOREOGRAPHY (RULING AY) — every set change is watchable travel.

   Each scene registers named PART MOVERS (sceneTravelPart) over groups that
   WRAP the built pieces: everything is built in its home pose and wrapped
   after the fact, so nothing repositions at build — the wrapper is the thing
   that travels.  The cemetery splits into two hill groups that run to the
   wings on x; the enclosed sets fly out on y like the flown pieces they are.
   The wagon (interior), the exterior and the flown sign keep their existing
   whole-group movers and cue-authored moves.  The bare stage carries no
   parts and changes instantly, which the engine allows on purpose.

   The four numbers below are FEEL constants — each is a one-line retune.
   --------------------------------------------------------------------------- */
const BJ_HILL_OUT   = 9.5;   // how far each hill group runs into its wing (m)
const BJ_HILL_SPEED = 2.0;   // m/s — the graveyard empties in ~4.8s
const BJ_PART_OUT   = 10.5;  // fly-out for the enclosed sets: clears the 9.2m
                             // header plus a margin, BJ_SIGN_OUT's own logic
const BJ_FLY_SPEED  = 1.8;   // m/s — a flown room clears in ~5.8s

/* ---------------------------------------------------------------------------
   ONE ROOM, THREE DRESSINGS (RULING AQ)

   The owner's photographs settle it: the Maitlands house, the Deetz house and
   the Beetlejuice house are plainly the SAME ARCHITECTURE — the same swooping
   ceiling, the same staircase, the same fireplace in the same corner —
   redressed three times.  So the wagon carries one shell and three dressings
   that take turns on it.

   A dressing is built exactly the way a scene was, which is why the
   redecorated room's own code moved across without a line changing: it is
   handed {group} and goes on calling .group.add().
   --------------------------------------------------------------------------- */
/* the hard black-and-white stripe the takeover paints everything in.  Vertical
   for the walls, horizontal for the furniture and the worm. */
/* THE SIGN'S LAMPS ON A CUE.  `signCol:'#ff1e10'` throws every bulb and tube
   on the marquee over to one colour; `signCol:null` restores what it was built
   with.  A cue that says nothing leaves it alone, which is what lets one cue
   turn it red and eight later cues keep it red without repeating themselves. */
function setSignLamps(hex){
  if(!SHOW.signLamps) return;
  SHOW.signLamps.forEach(r=>{
    if(hex){
      r.mat.color.set(hex); r.mat.emissive.set(hex); r.mat.emissiveIntensity = 2.1;
    } else {
      r.mat.color.copy(r.c); r.mat.emissive.copy(r.e); r.mat.emissiveIntensity = r.ei;
    }
  });
}
function bjStripeTex(vertical){
  const W = 512, H = 512, c = cvs(W, H), g = c.getContext('2d');
  g.fillStyle = '#efe9dd'; g.fillRect(0, 0, W, H);
  g.fillStyle = '#141018';
  const band = 44;
  for(let i = 0; i < W/band; i += 2){
    if(vertical) g.fillRect(i*band, 0, band, H);
    else         g.fillRect(0, i*band, W, band);
  }
  /* they are painted by hand, so the edges wobble */
  g.globalAlpha = 0.5;
  for(let i = 0; i < 90; i++){
    g.fillStyle = Math.random() < 0.5 ? '#141018' : '#efe9dd';
    if(vertical) g.fillRect(rnd(0, W), rnd(0, H), 3, rnd(20, 90));
    else         g.fillRect(rnd(0, W), rnd(0, H), rnd(20, 90), 3);
  }
  g.globalAlpha = 1;
  const t = tex(c, 1, 1);
  t.wrapS = t.wrapT = T.RepeatWrapping;
  return t;
}
function bjDressing(sc, key){
  const g = new T.Group();
  g.name = 'dress:' + key;
  sc.group.add(g);
  (sc.dress || (sc.dress = {}))[key] = g;
  return {group:g};
}
function bjDress(scOrName, key){
  const sc = (typeof scOrName === 'string') ? sceneFind(scOrName) : scOrName;
  if(!sc || !sc.dress || !sc.dress[key]) return null;
  sc.dressOn = key;
  bjRedress(sc);
  return key;
}
/* sceneShow enables the layers of every descendant when a set comes on, which
   would light all three dressings at once.  sceneApply calls this after. */
function bjRedress(sc){
  if(!sc || !sc.dress) return;
  for(const k of Object.keys(sc.dress)){
    const on = (k === sc.dressOn), g = sc.dress[k];
    g.userData.sceneOff = !on;
    if(typeof setPieceVisible === 'function') setPieceVisible(g);
    g.traverse(o=>{ if(on) o.layers.set(0); else o.layers.disableAll(); });
  }
}
/* an enclosed set is a flown piece (RULING AY): the whole of it goes out
   through the header on one named part, 'all'.  Called AFTER the scene is
   built: every existing child — meshes and dressing groups alike — moves
   into the wrapper without its transform changing, because both the scene
   group and the wrapper sit at the origin. */
function bjFlyWhole(sc){
  const g = new T.Group();
  g.name = 'bj:' + sc.name + ':all';
  while(sc.group.children.length) g.add(sc.group.children[0]);
  sc.group.add(g);
  sceneTravelPart(sc, 'all', g, 'y', 0, BJ_PART_OUT, BJ_FLY_SPEED);
  /* RULING BQ — AND THAT IS ALREADY A PARK.  A set flown out on `all` is standing
     in the grid, which is exactly where a real flown set lives between its
     scenes, so it only has to be DECLARED: no second mover, no new number.
     Measured (tools/parked.js): all five land at y 10.50 with their tops between
     15.63 and 19.70 against a grid at 25, clear of the brick and both wing walls,
     and NOT ONE RAY of 1025 from a stalls eye reaches any of them. */
  scenePark(sc);
  return g;
}

/* ---- the graveyard backdrop, repainted to the production photograph
   (RULING AW): a deep teal-to-indigo night sky, an ENORMOUS pale moon
   upper-stage-left-of-centre with painted grey craters and the halo it
   throws, and banks of blue-grey cloud streaked horizontally around and
   behind it, lit pale from below.  No painted ground row any more — the
   hills, stones and trees are CUT pieces downstage of this cloth now, so
   painting them here would double every silhouette. ---- */
function bjBackdropTex(){
  const W = 2048, H = 1024, c = cvs(W, H), g = c.getContext('2d');
  /* the cloth hangs (D.procW + 6) x 11.5, the canvas is 2:1 — anything meant
     to read ROUND on the cloth is drawn wider by this much in canvas space */
  const SQX = (W * 11.5) / (H * (D.procW + 6));
  /* the sky: teal at the horizon climbing into indigo-black */
  const sky = g.createLinearGradient(0, 0, 0, H);
  sky.addColorStop(0,    '#050e18');
  sky.addColorStop(0.40, '#0d2436');
  sky.addColorStop(0.72, '#1a2a52');
  sky.addColorStop(1,    '#283462');
  g.fillStyle = sky; g.fillRect(0, 0, W, H);
  /* the field darkens into both top corners, the way the photo has it */
  for(const cx of [0, W]){
    const v = g.createRadialGradient(cx, 0, 40, cx, 0, W*0.55);
    v.addColorStop(0, 'rgba(2,6,12,.62)');
    v.addColorStop(1, 'rgba(2,6,12,0)');
    g.fillStyle = v; g.fillRect(0, 0, W, H);
  }
  /* one cloud bank: a run of flat overlapping lumps with a pale underside —
     the banks are LIT FROM BELOW by the moon, so the light edge hangs under
     the dark body, not over it */
  const bank = (bx, by, bw, lump, body, under)=>{
    for(let i = 0; i < lump; i++){
      const x = bx + (i/(lump-1) - 0.5)*bw + rnd(-30, 30);
      const y = by + rnd(-14, 14);
      const rx = rnd(90, 170)*SQX, ry = rnd(22, 42);
      g.fillStyle = body;
      g.save(); g.translate(x, y); g.scale(rx, ry);
      g.beginPath(); g.arc(0, 0, 1, 0, 6.283); g.fill(); g.restore();
      g.fillStyle = under;
      g.save(); g.translate(x, y + ry*0.72); g.scale(rx*0.86, ry*0.34);
      g.beginPath(); g.arc(0, 0, 1, 0, 6.283); g.fill(); g.restore();
    }
  };
  /* the banks behind the moon, working down the cloth */
  bank(W*0.30, H*0.22, W*0.52, 7, 'rgba(38,52,72,.55)',  'rgba(150,172,196,.20)');
  bank(W*0.72, H*0.34, W*0.50, 7, 'rgba(44,60,82,.58)',  'rgba(168,190,212,.26)');
  bank(W*0.24, H*0.48, W*0.60, 8, 'rgba(50,66,88,.60)',  'rgba(176,198,218,.30)');
  bank(W*0.66, H*0.62, W*0.58, 8, 'rgba(42,56,76,.55)',  'rgba(160,182,204,.26)');
  bank(W*0.32, H*0.76, W*0.72, 9, 'rgba(34,46,64,.50)',  'rgba(140,160,182,.20)');
  /* horizontal streaking through the banks — it is scenic paint, laid
     sideways with a wide brush */
  for(let i = 0; i < 70; i++){
    const y = rnd(H*0.14, H*0.86);
    g.fillStyle = Math.random() < 0.5 ? 'rgba(180,200,220,.05)' : 'rgba(8,14,24,.07)';
    g.fillRect(rnd(-60, W*0.7), y, rnd(W*0.2, W*0.55), rnd(2, 6));
  }
  /* THE MOON — enormous, a third the height of the cloth, hung upper-stage-
     left-of-centre (stage left is canvas right: u=1 lands at world +x). */
  const mx = W*0.60, my = H*0.30, mr = H*0.167;      // ry: diameter ~ H/3
  const halo = g.createRadialGradient(mx, my, mr*0.6, mx, my, mr*2.8);
  halo.addColorStop(0,    'rgba(214,228,238,.42)');
  halo.addColorStop(0.45, 'rgba(190,208,224,.16)');
  halo.addColorStop(1,    'rgba(190,208,224,0)');
  g.save(); g.translate(mx, my); g.scale(SQX, 1); g.translate(-mx, -my);
  g.fillStyle = halo;
  g.beginPath(); g.arc(mx, my, mr*2.8, 0, 6.283); g.fill();
  /* the disc, pale and bone-coloured */
  g.fillStyle = '#e7e3d3';
  g.beginPath(); g.arc(mx, my, mr, 0, 6.283); g.fill();
  /* the craters, painted grey and clearly meant — each a soft-edged pool
     with a darker rim on its lower side, the way a scenic artist shades one */
  const craters = [[-0.34,-0.30,0.20],[0.22,-0.42,0.13],[0.44,0.06,0.17],
                   [-0.08,0.16,0.24],[-0.52,0.28,0.12],[0.18,0.44,0.15],
                   [-0.24,-0.02,0.10],[0.50,-0.28,0.09]];
  for(const cr of craters){
    const x = mx + cr[0]*mr, y = my + cr[1]*mr, r = cr[2]*mr;
    g.fillStyle = 'rgba(148,146,132,.42)';
    g.beginPath(); g.arc(x, y, r, 0, 6.283); g.fill();
    g.fillStyle = 'rgba(112,110,98,.30)';
    g.beginPath(); g.arc(x, y + r*0.28, r*0.72, 0, 6.283); g.fill();
  }
  /* the shading that keeps the disc a body, not a plate */
  const sh = g.createRadialGradient(mx - mr*0.3, my - mr*0.3, mr*0.2, mx, my, mr);
  sh.addColorStop(0, 'rgba(255,255,246,.16)');
  sh.addColorStop(0.75, 'rgba(120,124,120,0)');
  sh.addColorStop(1, 'rgba(96,100,104,.28)');
  g.fillStyle = sh;
  g.beginPath(); g.arc(mx, my, mr, 0, 6.283); g.fill();
  g.restore();
  /* and two thin streaks crossing the lower quarter of the disc — the banks
     run AROUND the moon, and one of them runs in front */
  for(const st of [[my + mr*0.55, 0.42], [my + mr*0.85, 0.34]]){
    g.fillStyle = 'rgba(40,54,74,' + st[1] + ')';
    g.fillRect(mx - mr*SQX*1.7, st[0] - 12, mr*SQX*3.4, 24);
    g.fillStyle = 'rgba(170,192,214,.18)';
    g.fillRect(mx - mr*SQX*1.5, st[0] + 10, mr*SQX*3.0, 6);
  }
  return tex(c, 1, 1);
}

/* ---- the house-exterior DROP, painted to the production photograph
   (RULING AW): a deliberately wonky grey-brown clapboard house, tall and
   narrow, steep gable and a small tower, crooked dark windows, a dark
   porch with steps at its base, spindly bare black trees flanking it and
   a pale moon low behind.  Storybook-crooked on purpose: the verticals
   lean and the boards waver, because the cloth in the photo does.
   Painted for a 12.6 x 8.7 cloth — X()/Y() convert cloth-metres to
   pixels, so every measurement below is a stage measurement. ---- */
function bjHouseClothTex(){
  const W = 1024, H = 1024, c = cvs(W, H), g = c.getContext('2d');
  const X = mtr => W/2 + mtr*(W/12.6);       // metres off centre -> px
  const Y = mtr => H - mtr*(H/8.7);          // metres above the deck -> px
  const SX = W/12.6, SY = H/8.7;             // px per metre, each way
  /* the drop's own night sky, darker than the sky cloth it plays against */
  const sky = g.createLinearGradient(0, 0, 0, H);
  sky.addColorStop(0,    '#080f1d');
  sky.addColorStop(0.55, '#152238');
  sky.addColorStop(1,    '#20304c');
  g.fillStyle = sky; g.fillRect(0, 0, W, H);
  for(const cx of [0, W]){
    const v = g.createRadialGradient(cx, 0, 30, cx, 0, W*0.5);
    v.addColorStop(0, 'rgba(3,6,12,.55)'); v.addColorStop(1, 'rgba(3,6,12,0)');
    g.fillStyle = v; g.fillRect(0, 0, W, H);
  }
  /* the pale moon, low, about to be half-lost behind the house.  The canvas
     is square and the cloth is not (12.6 x 8.7), so anything meant to read
     ROUND on the hung drop is drawn under an x-squash — the same trick the
     backdrop painter's SQX block uses; without it this disc read as a
     1.52m x 1.05m egg on stage, on the most looked-at element of the cloth */
  const mx = X(2.5), my = Y(5.1), mr = 1.05*SY, KX = SX/SY;
  const halo = g.createRadialGradient(mx, my, mr*0.5, mx, my, mr*2.4);
  halo.addColorStop(0, 'rgba(210,222,232,.36)'); halo.addColorStop(1, 'rgba(210,222,232,0)');
  g.save(); g.translate(mx, my); g.scale(KX, 1); g.translate(-mx, -my);
  g.fillStyle = halo; g.beginPath(); g.arc(mx, my, mr*2.4, 0, 6.283); g.fill();
  g.fillStyle = '#ddd8c6'; g.beginPath(); g.arc(mx, my, mr, 0, 6.283); g.fill();
  g.fillStyle = 'rgba(150,148,134,.32)';
  g.beginPath(); g.arc(mx - mr*0.2, my + mr*0.15, mr*0.3, 0, 6.283); g.fill();
  g.beginPath(); g.arc(mx + mr*0.35, my - mr*0.3, mr*0.2, 0, 6.283); g.fill();
  g.restore();
  /* the ground the whole picture stands on: a near-black rise */
  g.fillStyle = '#0b0d12';
  g.beginPath(); g.moveTo(0, H);
  g.lineTo(0, Y(0.45));
  for(let i = 0; i <= 12; i++)
    g.lineTo(i*W/12, Y(0.45 + Math.sin(i*1.7)*0.14));
  g.lineTo(W, H); g.closePath(); g.fill();
  /* one spindly bare black tree each side — a trunk that wanders and
     limbs that fork off it, drawn as strokes */
  g.lineCap = 'round';
  const tree = (bx, top, dir)=>{
    g.strokeStyle = '#0a0908';
    g.lineWidth = 0.16*SX;
    g.beginPath(); g.moveTo(X(bx), Y(0.3));
    g.quadraticCurveTo(X(bx + dir*0.35), Y(top*0.45), X(bx + dir*0.15), Y(top));
    g.stroke();
    for(let i = 0; i < 6; i++){
      const yy = top*0.35 + i*(top*0.55)/5, sd = (i % 2 ? -1 : 1);
      g.lineWidth = (0.07 - i*0.006)*SX;
      g.beginPath(); g.moveTo(X(bx + dir*0.22*(1 - yy/top)), Y(yy));
      g.quadraticCurveTo(X(bx + sd*0.9), Y(yy + 0.5), X(bx + sd*(1.3 + i*0.12)), Y(yy + 1.1 + i*0.1));
      g.stroke();
    }
  };
  tree(-4.7, 5.4,  1);
  tree( 4.5, 4.8, -1);
  /* THE HOUSE.  The whole thing leans a couple of degrees, and every
     element leans a little more on its own account. */
  g.save();
  g.translate(X(-0.3), Y(0)); g.rotate(-0.025); g.translate(-X(-0.3), -Y(0));
  const quad = (pts, fill)=>{ g.fillStyle = fill; g.beginPath();
    g.moveTo(X(pts[0][0]), Y(pts[0][1]));
    for(let i = 1; i < pts.length; i++) g.lineTo(X(pts[i][0]), Y(pts[i][1]));
    g.closePath(); g.fill(); };
  /* the clapboard body — a quadrilateral whose verticals do not agree */
  const BL = [-2.15, 0.85], BR = [1.55, 0.80], TR = [1.78, 5.30], TL = [-2.42, 5.55];
  quad([BL, BR, TR, TL], '#5c5346');
  /* the boards: wavering horizontal strokes, clipped to the body */
  g.save();
  g.beginPath(); g.moveTo(X(BL[0]), Y(BL[1])); g.lineTo(X(BR[0]), Y(BR[1]));
  g.lineTo(X(TR[0]), Y(TR[1])); g.lineTo(X(TL[0]), Y(TL[1])); g.closePath(); g.clip();
  for(let b = 0; b < 19; b++){
    const yy = 0.95 + b*0.25;
    g.strokeStyle = (b % 4 === 2) ? 'rgba(190,178,156,.10)' : 'rgba(16,13,10,.38)';
    g.lineWidth = 2.2;
    g.beginPath(); g.moveTo(X(-2.5), Y(yy + rnd(-0.03, 0.03)));
    g.quadraticCurveTo(X(rnd(-1.2, 0.6)), Y(yy + rnd(-0.09, 0.09)), X(1.9), Y(yy + rnd(-0.04, 0.04)));
    g.stroke();
  }
  /* the wall darkens toward the ground, lived-in and damp */
  const dg = g.createLinearGradient(0, Y(0.8), 0, Y(3.2));
  dg.addColorStop(0, 'rgba(10,9,8,.45)'); dg.addColorStop(1, 'rgba(10,9,8,0)');
  g.fillStyle = dg; g.fillRect(0, 0, W, H);
  g.restore();
  /* the steep gable, its ridge off-centre because everything here is */
  quad([TL, TR, [-0.42, 8.05]], '#554c40');
  /* the roof: two slopes in two darks, overhanging the walls */
  quad([[-2.75, 5.42], [-0.42, 8.28], [-0.10, 8.20], [-2.35, 5.30]], '#2a2320');
  quad([[-0.42, 8.28], [2.10, 5.18], [1.72, 5.08], [-0.12, 7.95]], '#1c1815');
  /* the small tower, right of the gable, leaning harder than the house */
  quad([[0.95, 4.9], [2.15, 4.85], [2.38, 6.85], [1.05, 6.95]], '#524940');
  quad([[0.82, 6.80], [2.55, 6.72], [1.85, 8.35]], '#1e1a17');
  /* crooked dark windows: a hole, a pale warped frame, a sill */
  const win = (wx, wy, ww, wh, lean)=>{
    g.save();
    g.translate(X(wx), Y(wy)); g.rotate(lean);
    g.fillStyle = '#0c0b10';
    g.fillRect(-ww/2*SX, -wh/2*SY, ww*SX, wh*SY);
    g.strokeStyle = 'rgba(196,184,162,.55)'; g.lineWidth = 3;
    g.strokeRect(-ww/2*SX, -wh/2*SY, ww*SX, wh*SY);
    g.beginPath(); g.moveTo(0, -wh/2*SY); g.lineTo(0, wh/2*SY);
    g.moveTo(-ww/2*SX, 0); g.lineTo(ww/2*SX, 0); g.stroke();
    g.fillStyle = 'rgba(196,184,162,.35)';
    g.fillRect(-ww/2*SX - 3, wh/2*SY, ww*SX + 6, 5);
    g.restore();
  };
  win(-1.35, 4.35, 0.70, 1.05, -0.07);
  win( 0.85, 4.20, 0.62, 0.95,  0.06);
  win(-1.30, 2.60, 0.72, 1.05,  0.05);
  win( 1.65, 5.85, 0.50, 0.72,  0.09);      // the tower's own window
  win(-0.45, 6.55, 0.46, 0.62, -0.06);      // up in the gable
  /* the porch, dark across the base: deck, posts, its own low roof */

/* ---- the show curtain: a hard vertical stripe, our own colours ---- */
function bjCurtainCanvas(){
  const W = 1024, H = 512, c = cvs(W, H), g = c.getContext('2d');
  /* the ground: deep violet, going bluer stage left and hotter stage right,
     which is how the cloth reads in the photograph */
  const base = g.createLinearGradient(0, 0, W, 0);
  base.addColorStop(0,    '#2a1a63');
  base.addColorStop(0.34, '#3b1f7a');
  base.addColorStop(0.62, '#57208a');
  base.addColorStop(1,    '#3a2170');
  g.fillStyle = base; g.fillRect(0, 0, W, H);
  /* it is a DRAPE, so the colour lives in the pleats — a bright edge and a
     shadowed fold every band, not a flat wash */
  const band = W / 26;
  for(let i = 0; i < 26; i++){
    const gr = g.createLinearGradient(i*band, 0, (i+1)*band, 0);
    gr.addColorStop(0,    'rgba(0,0,0,.46)');
    gr.addColorStop(0.30, 'rgba(150,110,225,.20)');
    gr.addColorStop(0.52, 'rgba(190,150,255,.28)');
    gr.addColorStop(0.74, 'rgba(90,60,170,.10)');
    gr.addColorStop(1,    'rgba(0,0,0,.46)');
    g.fillStyle = gr; g.fillRect(i*band, 0, band, H);
  }
  /* THE SCROLLWORK.  The cloth is covered in loose black curls — big lazy
     spirals with hooks coming off them, drawn the size of a person and
     scattered over the whole drop. */
  g.lineCap = 'round'; g.lineJoin = 'round';
  const curl = (cx, cy, s, turns, dir)=>{
    g.beginPath();
    let a = 0, r = 2 * s;
    g.moveTo(cx + r, cy);
    const steps = Math.round(turns * 14);
    for(let i = 1; i <= steps; i++){
      a = dir * (i / 14) * 6.283;
      r = (2 + i * 0.30) * s;
      g.lineTo(cx + Math.cos(a) * r, cy + Math.sin(a) * r * 0.86);
    }
    g.stroke();
  };
  const sprig = (x, y, s, dir)=>{
    g.beginPath();
    g.moveTo(x, y);
    g.bezierCurveTo(x + dir*18*s, y - 26*s, x + dir*40*s, y - 30*s, x + dir*46*s, y - 6*s);
    g.bezierCurveTo(x + dir*50*s, y + 14*s, x + dir*32*s, y + 20*s, x + dir*26*s, y + 6*s);
    g.stroke();
  };
  for(let i = 0; i < 46; i++){
    const x = rnd(-40, W + 40), y = rnd(-30, H + 30), s = 0.5 + Math.random()*1.25;
    g.strokeStyle = 'rgba(8,4,16,' + (0.55 + Math.random()*0.35).toFixed(2) + ')';
    g.lineWidth = 4.5 * s;
    curl(x, y, s * 2.1, 1.2 + Math.random()*0.9, Math.random() < 0.5 ? 1 : -1);
    sprig(x + rnd(-30, 30), y + rnd(-40, 40), s, Math.random() < 0.5 ? 1 : -1);
  }
  /* the seams between the widths of fabric, and the soft floor bounce */
  for(let i = 1; i < 6; i++){
    g.strokeStyle = 'rgba(0,0,0,.30)'; g.lineWidth = 2;
    g.beginPath(); g.moveTo(i*W/6, 0); g.lineTo(i*W/6, H); g.stroke();
  }
  const gr2 = g.createLinearGradient(0, H, 0, H*0.55);
  gr2.addColorStop(0, 'rgba(120,60,190,.30)');
  gr2.addColorStop(1, 'rgba(120,60,190,0)');
  g.fillStyle = gr2; g.fillRect(0, 0, W, H);
  const t = tex(c, 1, 1);
  return {tex: t};
}

/* ---- the marquee: two decks of BETELGEUSE in red neon inside a bulb

  g.fillStyle = '#1c0a10'; g.fillRect(12, 12, W - 24, H - 24);

    g.strokeStyle = 'rgba(190,26,10,.45)'; g.lineWidth = 17; draw();
    g.strokeStyle = '#ff3d18';             g.lineWidth = 8;  draw();

SHOWS.beetlejuice = {

  load(){

         put on it is destroyed for every show that follows — `sky` is stock
         and is already in the palette, so it is simply hung. */
      SHOW.goods.push('bjBackdrop');
      buildGoodsPalette();
    }

    /* ---- the hang ---- */
    hangGoods(FLY[0], SHOW.curtainKey);
    FLY[0].target = TRIMS[SHOW.curtainKey]; FLY[0].travTarget = 0; FLY[0].open = 0;
    hangGoods(FLY[1], 'border');    FLY[1].target = TRIMS.border;
    hangGoods(FLY[2], 'legs');      FLY[2].target = inTrimOf(FLY[2]);
    hangGoods(FLY[3], 'border');    FLY[3].target = TRIMS.border;
    hangGoods(FLY[4], 'electric');  FLY[4].target = 9.2;
    hangGoods(FLY[5], 'legs');      FLY[5].target = inTrimOf(FLY[5]);
    hangGoods(FLY[6], 'truss');     FLY[6].target = 11.4;
    hangGoods(FLY[8], 'electric');  FLY[8].target = 10.4;
    /* the graveyard's own backdrop is IN at the top of the show; the sky
       belongs to act two and waits out until then */
    /* THE TWO DEEPEST LINES IN THE HOUSE, and it has to be that way round: a
       cloth is the last thing upstage, so anything hung downstage of a set is
       hanging in FRONT of it.  These went in on lines 8 and 10 first time and
       put the backdrop at z=-6.10, ahead of the interior wall at -9.20 and

    /* THE BACKDROP IS ON THE FINAL LINESET (owner: the house parks 'behind
       the final line set witch will have the backdrop').  The sky takes the
       one in front of it; the two are never in together, so the order between
       them is free and the wagon's hiding place is what decides it. */
    hangGoods(FLY[13], 'bjBackdrop'); FLY[13].target = TRIMS.bjBackdrop;
    hangGoods(FLY[12], 'sky');        FLY[12].target = OUT_TRIM;
    FLY.forEach(ls=>{ ls.pos = ls.target; ls.group.position.y = ls.pos; });

    sceneShow('cemetery');           // instant: boot snaps the hills home
    RIG.haze = 0.55;                 // the beam fan is in every reference frame
    plotBeetlejuice();
    standByAtTheTop();
  }
};

/* ============================================================================
   THE PLOT — the opening sequence.

   Every TIME in these comments is measured off the recording; every LEVEL and
   every FOCUS is interpreted onto our 25 channels.  Fade durations are the
   measured ones where a slope was clean inside a single held shot.  The rest
   of the show's cues arrive with the full measured list.
   ========================================================================== */
function plotBeetlejuice(){
  const FRONT = [1,2,3,4,5,6], BOOM = [7,8], WASH = [9,10,11,12,13,14],
        BACK = [15,16,17,18], CYC = [19,20,21,22], MOVE = [23,24], SPOT = 25;
  /* the audience rig (RULING BC).  Named AUDM, not AUD — AUD is p5j's audio
     state object, and shadowing it in here would be a quiet disaster. */
  const BLIND = [26,27,28,29,30,31,32,33], AUDM = [34,35,36,37,38,39];
  const all = v => FIXTURES.forEach(f=>{ f.level = v; });
  const set = (list, v, col)=>list.forEach(n=>{
    const f = chan(n); if(!f) return; f.level = v; if(col) f.color.set(col); });
  const one = (n, v, col)=>set([n], v, col);

  /* the front of house, thrown UP onto the cloth for the curtain cues */
  const onTheCloth = ()=>aimFrontAt(FRONT, 0, 7.4, -1.0);

  /* --------------------------------------------------------------------
     THE PLOT, AS THE OWNER GAVE IT.

     Every `at` below is one of his timestamps, converted.  He watched the
     recording and wrote the set changes out himself, and where his list
     disagreed with what the measurement had built, his list won — which is
     most of act one.  The one place the two AGREE is the strongest thing
     here: his act break, 1:11:02, is second 4262, exactly where
     blackdetect found the show's longest blackout.  The two timelines
     share a base, so his numbers went straight in.

     `hold:true` is a cue that arms nothing and waits for GO.  There are
     exactly two — the pre-show and the interval — because he asked for the
     show to advance from pre-show "when you press start" and for the
     second half to begin "when you press a button on the consol".
     -------------------------------------------------------------------- */
  const looks = [
    /* ============ PRE-SHOW ============ */
    /* "Play pre show music i have provided and set the house lights low."
       The blinders are built and OFF — "dont have them on they are for later" —
       and the audience movers drift over the seating, slowly, green to purple
       and back (rulings BC and BD).

       RULING BM — THE HAZE AND THE HOUSE, so the beams read.  "make it so in
       pre show and the start of show light stuff you can see the actual beams
       better."  Two numbers, both OURS and neither of them his: his four text
       files say nothing about haze anywhere, and 0.45 was our reading of the
       word "low".

       HAZE 0.15 -> 0.50.  A beam draws at uHaze = 0.25 + haze*1.15, so 0.15
       was 0.42 against a mid-show 0.88-1.06 — the LEAST haze in the whole
       94-cue plot, in the one stretch that is nothing BUT beams, because the
       curtain is in and there is no stage picture to light.  The show's own
       blurb is "more haze than air".  It costs no draw call: the beam is
       rasterised whenever it is lit at all, and haze only sets its opacity.

       HOUSE 0.45 -> 0.30, which is the other half of the same problem and was
       measured, not guessed: at 0.45 the house lights put ~2.0-2.4 on a seat
       while the whole audience rig peaked at ~1.0.  The room was twice as
       bright as the effect in it.  0.30 is still "low" and still his word;
       if he wants the foyer feel back it is one line.

       THE FOYER IS UP HERE AND OUT AT GO (RULING BH) — "make sure the lobby
       lights get turned of at the start of a show".  It comes back at the
       interval and goes out again for act two, because the audience walks out
       into it and then back in.  It is the only circuit in this plot that is
       ON at the pre-show and OFF for the show, which is what a front of house
       is.  These four cues are the only ones in all five productions that say
       anything about it at all; every other cue leaves it exactly alone. */
    {at:33, n:0.5, label:'PRE-SHOW — house low, curtain in, the sign lit', fade:0,
     house:0.30, lobby:0.9, haze:0.50, curtain:'shut', scene:'cemetery',
     backdrop:'in', hold:true,
     audio:{play:'preshow'},
     fx:{on:'aud', kind:'wander', cols:['#2fbf5f','#7f3fbf']},
     look(){ all(0); onTheCloth(); set(FRONT, 0.45, '#e8d2a8');
       set(AUDM, 0.55, '#2fbf5f'); }},

    /* ============ THE TOP OF THE SHOW ============ */
    /* GO.  "have it stop the first audio and start the second (start the audio
       at time stamp 35 seconds)" — so this cue's own `at` IS 35, and from here
       on the music is the clock: every cue below fires when the track reaches
       its `at` (RULING BB).  With no audio present the follow chain runs it on
       the same numbers.

       "The lights around the prosinum all turn red and all the lights on the
       beetlejuice sign go bright red." */
    {at:35, n:1, label:'GO — the proscenium and the sign go red', fade:1.5,
     house:0, lobby:0, haze:0.60, curtain:'shut', scene:'cemetery', backdrop:'in',
     audio:{play:'act1', at:35, stop:'preshow'}, signCol:'#ff1e10',
     look(){ all(0); set(BLIND, 0.85, '#ff1e10'); }},

    /* "From 1:03 to 1:05 have all the lights that are in the audience area be
       purple and sweep up then at 1:05 they go dark (make sure the beetljuice

    {at:63, n:1.1, label:'1:03 — the house sweeps up, purple', fade:0,

     house:0, haze:0.65, curtain:'shut', scene:'cemetery', backdrop:'in',
     look(){ all(0); }},

    /* "Then from 1:06 to 1:09 do the same as last cue." */
    {at:66, n:1.3, label:'1:06 — and again', fade:0,
     house:0, haze:0.65, curtain:'shut', scene:'cemetery', backdrop:'in',
     fx:{on:'aud', kind:'sweep', col:'#8a2fe0', secs:3},

    {at:76, n:1.5, label:'1:16 — blinders flash white; the curtain and the sign go out',

     move:{scene:'bjSign', off:BJ_SIGN_OUT},

    {at:86, n:1.7, label:'1:26 — the pattern stops, one more white flash', fade:0,
     house:0, haze:0.65, curtain:'out', scene:'cemetery', backdrop:'in',

    {at:88, n:2, label:'the stage fades up blue — the graveyard', fade:6,
     house:0, haze:0.6, curtain:'out', scene:'cemetery', backdrop:'in',
     signCol:null,
     look(){ all(0);
       set(CYC, 0.55, '#2f5f9c'); set(BACK, 0.42, '#4a78b4');
       set(WASH, 0.18, '#5f7fa8'); set(BOOM, 0.30, '#3f6ea6'); }},

    /* ======================================================================
       ACT ONE, AS HE WROTE IT.

    {at:210, n:3, label:'3:30 — just downstage right, white', fade:2.5,
